# Communication et présentation — format utile

## Message court (pour jury et nouveaux membres)
« EpiVerse réunit les services de la vie étudiante dans une application web et mobile, avec un campus virtuel 2.5D personnalisable. Notre priorité est de livrer un parcours simple et démontrable, puis d'ajouter progressivement les services sociaux et l'IA. »

## Ce qui est présenté
- **Ce qui fonctionne** : code intégré, tests, PR et démos accessibles.
- **Ce qui se développe** : PR et branches identifiées, date et responsable.
- **Ce qui reste à faire** : tickets chiffrés et jalons.
- **Ce qui est vision** : modules hors MVP et leurs risques.

## Canaux
| Canal | But | Responsable |
|---|---|---|
| GitHub README | Comprendre le projet en 1 minute | Estelle |
| GitHub Issues/PR | Suivre le travail et vérifier | Leads |
| GitHub docs/pilotage | Préparer suivi EPITECH et audit | Estelle |
| Microsoft Teams | Échanges et réunions | Tous |
| Figma | Conception et validations visuelles | Soumia |

## Démonstration courte
1. Problème visé et périmètre MVP.
2. Ouvrir la partie vraiment disponible.
3. Montrer un parcours et le test associé.
4. Afficher les KPI et le reste à faire.
5. Indiquer ce qui n'est pas encore livré.

**Ne pas utiliser** de visuel ou de vidéo fictive comme preuve de fonctionnalité.
