# Data, analytics et IA — Thomas est lead

**Équipe permanente : Thomas (lead), Belaid et Lina.** Belaid soutient temporairement le backend avec Eckson, Lina le frontend avec Philimon et Thomas le campus avec Julien.

## En parallèle du frontend
| Étape | Travail | Critère de fin |
|---|---|---|
| D1 | Définir événements produit : affichage, clic, inscription, ouverture campus | Contrat versionné + exemples JSON fictifs |
| D2 | Définir champ, consentement, durée, accès et suppression | Accord sécurité/RGPD et tests |
| D3 | Générer des données fictives réalistes | Fixtures reproductibles, sans données personnelles |
| D4 | Contrôler qualité : complétude, doublons, expiration | Test automatique + rapport |
| D5 | Établir une baseline de recommandation simple | Règles et métriques reproductibles |
| D6 | Évaluer une IA plus avancée | Seulement si données utilisables, temps et besoin démontré |

## KPI Data/IA proposés (ne pas annoncer comme atteints)
- Complétude des champs critiques ≥ 95 %.
- Doublons ≤ 1 % sur catalogue de test.
- Événements périmés recommandés : 0.
- Baseline non-IA disponible même si le moteur IA est indisponible.
- Évaluations reproductibles avec version du jeu et graine fixe.

## Conditions du retour au pôle
Application reliée à l'API, structures stables, premières interactions fictives exploitables et plan de tracking validé. Les renforts sont **temporaires**, pas un changement d'équipe définitif.
